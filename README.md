# Project Atlas 🚀

Engineering software for asteroid exploration and mission planning.

---

## Vision

Project Atlas is a long-term software project focused on helping engineers and researchers explore, analyze, and eventually plan missions to near-Earth asteroids.

The goal is to build this project over the next several years while studying Intelligent Systems Engineering at Indiana University.

---

## Version

Current Version: **0.1.0**

Status: 🟢 In Development

---

## Features (Planned)

- Search real asteroids
- Display asteroid information
- Visualize asteroid orbits
- Estimate mission difficulty
- Plan future missions
- AI-assisted mission recommendations
